Research software · Earth-observation mission planning

Constrained satellite scheduling laboratory

OrbitOps is a reproducible environment for comparing exact, heuristic, stochastic-search, and reinforcement-learning policies under a shared feasibility model.

Problem class
Single-satellite, offline task scheduling
Objective
Lexicographic value, completion, and slew minimization
Constraints
Visibility, temporal overlap, attitude, energy, and storage
Evaluation
Independent replay through one deterministic simulator

Model scope. The current release uses precomputed visibility windows and a notional ground track; it does not claim high-fidelity orbit propagation.
